# Siobhan Stack: Technical Portfolio

[Visit the published portfolio](https://siosta87.github.io/cyber-portfolio/)

This repository contains the Jekyll website for my cybersecurity work samples and learning journal. My separate automation repositories contain their own source code.

## Portfolio sections

- Security Audit
- Incident Report
- SQL Query
- Vulnerability Assessment
- TryHackMe Journal
- Incident Handler's Journal

## Where to edit

| Content | Location |
| --- | --- |
| Site title, location, social links, colors | _config.yml |
| About text and resume link | _includes/about.html |
| Project descriptions and document links | _posts/ |
| Project images | img/portfolio/ |
| Page layout and components | _layouts/ and _includes/ |

The site is published through GitHub Pages from the master branch. Linked Google Docs remain separate documents; edits to their contents do not require another website upload.
